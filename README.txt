JEJU PROJECT — REDESIGNED WEBSITE

Main pages:
- index.html — long editorial homepage with research question, highlights, timeline and exploration cards
- history.html — research context and full original timeline image
- culture.html — Jeju landscape, haenyeo culture, memory and identity
- media.html — interactive Google map and included project video
- ai-sources.html — project-provided bibliography and AI-use statement
- team.html — project team roles
- style.css — responsive documentary/editorial design
- script.js — mobile navigation and English/Korean toggle
- timeline.png and video.mp4 — original project assets

OPEN LOCALLY:
Unzip the package, keep every file in the same folder, then open index.html in a browser.
Images and embedded Google Map require an internet connection.

PUBLISH:
Use https://app.netlify.com/drop. Upload the extracted website folder (or follow the site's current instructions). Share the generated public URL with your classmates and teacher. Keep video.mp4 with the other files; it is about 61 MB and may make uploads slower.
